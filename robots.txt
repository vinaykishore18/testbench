# Testbench is an internal bench tool for one returns operation. It is not a
# product, it sells nothing, and there is no reason for it to appear in anyone's
# search results. Nothing here should be indexed, cached, summarised or used as
# training data.
#
# robots.txt is a request, not a control: a crawler that ignores it faces no
# obstacle. The X-Robots-Tag header and the noindex meta in the page are what
# actually keep it out of the search engines that honour either, and this file
# is the polite version of the same instruction for the crawlers that read it
# first. None of the three stops a determined scraper, and nothing can - a
# static site has to hand its files to whoever asks. What keeps the site safe
# is that there is nothing worth taking in it: no server, no database, no
# customer data, no credentials, and no internal detail (see .vercelignore).
