The mouse

Press each button on the mouse and watch it light up on the diagram. Side buttons on MMO mice usually send keyboard macros — click a thumb-pad key on the diagram, then press that button on the mouse, and it will bind and light up from then on.

Buttons

Side buttons on MMO and multi-button mice often ship as keyboard macros rather than mouse buttons. Anything the mouse sends as a key lands in the capture list below, so a 12-button pad still tests fully — press each one and watch a new line appear.

Sensor & tracking

CPI —

Drag to draw — a healthy sensor draws a smooth line, a failing one steps, jumps or drops out. For CPI: turn on raw mode, reset the count, swipe the mouse a measured distance in one straight pass, then type that distance in. Switch off pointer acceleration in the operating system first or the number will read high.

Click timing

Every gap between releasing a button and pressing it again, bucketed in 25 ms steps from 0 on the left to 600 ms on the right. Human clicking piles up in the middle. Bars in the first three red buckets are the mouse firing on its own.

Solid fields — dead & stuck pixels

A dead pixel stays black on every field. A stuck pixel stays one colour on every field. Dust wipes off; a fault does not.

Automatic run

The full run walks all eleven colour fields and all nine patterns on its own — 20 steps, about two minutes at 6 seconds each. Space pauses, → skips ahead, ← goes back, Esc stops. Quick run is the eight that catch most faults.

Single patterns

Stuck-pixel flush cycles colours fast over the whole screen; leave it running ten minutes on a stuck subpixel. It flashes rapidly — skip it if anyone nearby is sensitive to flashing.
