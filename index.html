Automatic run

The full run walks all eleven colour fields and all nine patterns on its own — twenty steps, about two minutes at six seconds each. Space pauses, → skips, ← goes back, Esc stops.

Solid fields

A dead pixel stays black on every field. A stuck pixel stays one colour on every field. Dust wipes off; a fault does not.

Single patterns

Stuck-pixel flush cycles colours fast over the whole screen; leave it running ten minutes on a stuck subpixel. It flashes rapidly — skip it if anyone nearby is sensitive to flashing.
